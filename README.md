# Neural Networks from Scratch using PyTorch
A ground-up, structured exploration of **neural networks using PyTorch**, focused on **fundamentals, internals, and first-principles understanding** rather than black-box usage.

This repository documents my journey of learning deep learning *from scratch* — starting with tensor operations and linear algebra, and gradually building up to neural networks, training loops, and optimization.

The emphasis is on **clarity, correctness, and intuition**: understanding *what happens*, *why it happens*, and *how PyTorch works under the hood*.


## 📌 Goals of This Repository
- Build a **strong foundation** in PyTorch and deep learning  
- Understand tensors, autograd, and neural networks deeply  
- Avoid shallow, copy-paste learning  
- Create a long-term **reference-style repository**  
- Prepare for advanced topics (CNNs, Transformers, research work)


## 🧠 Learning Philosophy
- Learn concepts **layer by layer**  
- Prefer **explicit code and explanations**  
- Use PyTorch as a tool, not a crutch  
- Treat notebooks as **chapters of a book**, not scratchpads


## 🧪 Topics Covered (So Far)
- Tensor creation and initialization  
- Element-wise arithmetic operations  
- In-place operations  
- Tensor reshaping and views  
- Reduction and statistical operations  
- Linear algebra (matmul, dot, transpose, inverse)  
- Activation functions and element-wise math  

More advanced topics will be added incrementally.


## 🚀 How This Repository Is Maintained
- Notebooks are written and executed in **Google Colab**  
- Clean markdown explanations accompany code  
- Large outputs are cleared before committing  
- Commits are structured and meaningful
